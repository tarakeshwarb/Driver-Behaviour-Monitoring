| Field | Value |
|-------|-------|

## Download Instructions

1. Download from the official source:
   - **IEEE DataPort**: https://ieee-dataport.org/documents/uah-driveset
   - **Alternative**: Contact the authors at `eduardo.romera@edu.uah.es`

2. Extract the ZIP archive into this directory:
   ```
   data/raw/UAH-DriveSet/
     D1/  D2/  D3/  D4/  D5/  D6/
     uah_driveset_reader/
     README
     LICENSE
   ```

3. Do **not** commit the dataset to Git. It is listed in `.gitignore`.

## File Formats

### RAW_ACCELEROMETERS.txt (space-separated, no header)
| Column | Description | Unit |
|--------|-------------|------|
| 1 | Timestamp (since route start) | s |
| 2 | Status (1 = valid) | — |
| 3 | ax_raw (longitudinal, raw) | g |
| 4 | ay_raw (lateral, raw) | g |
| 5 | az_raw (vertical, raw) | g |
| 6 | ax_filt (longitudinal, filtered) | g |
| 7 | ay_filt (lateral, filtered) | g |
| 8 | az_filt (vertical, filtered) | g |
| 9 | ax_grav (gravity-removed) | g |
| 10 | ay_grav | g |
| 11 | az_grav | g |

Sampling rate: **~10 Hz** (interval ≈ 0.1 s)

### RAW_GPS.txt (space-separated, no header)
| Column | Description | Unit |
|--------|-------------|------|
| 1 | Timestamp | s |
| 2 | Speed | km/h |
| 3 | Latitude | ° |
| 4 | Longitude | ° |
| 5 | Altitude | m |
| 6 | Num. satellites | — |
| 7 | HDOP | — |
| 8 | Bearing | ° |
| 9 | Longitudinal acceleration (Doppler) | m/s² |
| 10 | Lane lateral offset | — |
| 11 | Lane change flag | 0/1 |
| 12 | Overtaking flag | 0/1 |

Sampling rate: **~1 Hz**

### EVENTS_INERTIAL.txt
Reference inertial event annotations:
`timestamp  event_type  severity  latitude  longitude  datetime`

Event types: `2`=acceleration, `-2`=braking, `1`=turn-left, `-1`=turn-right

## Preprocessing Strategy

GPS (1 Hz) and IMU (10 Hz) are synchronised by **linear interpolation** of GPS
columns onto IMU timestamps. See `src/preprocessing.py:synchronise_sensors()`.

The dataset must be split **chronologically** (by trip folder name date prefix)
before feature normalisation is fitted, to prevent data leakage.
